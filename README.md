# HonyakuMiru お問い合わせ

[HonyakuMiru](https://honyakumiru.org/) の不具合報告、ご要望、お問い合わせを受け付ける公開リポジトリです。

[Issue を作成する](https://github.com/cuilinhao/honyakumiru-feedback/issues/new)

## 不具合を報告するとき

- ご利用の端末とブラウザ
- 起きたことと期待した動作
- 再現する手順

画像・原文・訳文の添付は任意です。Issue は公開されるため、個人情報、機密情報、API キー、アクセス権のない著作物を記載しないでください。

サイトのソースコードを公開するリポジトリではありません。決済や有料プランは現在提供していません。
